# Результаты

Проверено 1 ноября 2026 на Java 17.0.12, Maven 3.9.9, Windows.
Из 56 проверок прошли 54, упали 2.

## Токен с буквами G–Z

По ТЗ токен может содержать A–Z и цифры. При успешном ответе внешнего `/auth` отправляем LOGIN с токеном `ABCDEFGHIJKLMNOPQRSTUVWXYZ012345` (32 символа).

Ожидается `result: OK`, но получаем `result: ERROR` и сообщение о допустимом формате `^[0-9A-F]{32}$`.
Приложение отклоняет токен, который соответствует ТЗ. Тест: `validToken`.

## Пробел перед LOGIN

Отправляем корректный токен и `action= LOGIN` с пробелом в начале.
Тест ожидает ERROR, приложение возвращает OK.
В ТЗ перечислены LOGIN, ACTION и LOGOUT, но обработка пробелов отдельно не описана, поэтому это пока спорное расхождение. Тест: `invalidAction`.

Отчёт можно открыть командой `mvn allure:serve` после запуска тестов. Ответы сервиса прикреплены к шагам тестов.
